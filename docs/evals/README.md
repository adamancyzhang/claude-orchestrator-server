# Evals — 行为对照验证集

本目录维护一组**用户行为 → 可观察输出**的逐步验证文档，用来定期核对：

1. **用户层面**的输入（CLI 命令、TUI 键盘事件、消息内容）
2. **预期行为**（来自 `CLAUDE.md` 与 `docs/v0.7/`）
3. **实际行为**（从 `packages/*/src/` 静态推导，或真机运行后回填）
4. **差异**（含判定与修复方案）

每份文档专注**一个用户行为**，从最简单的启动开始，逐步覆盖完整产品体验。

## 编号规则

- `0X-...md` 表示场景编号；数字越小越基础（启动 < 单消息 < 决策链 < 链派生）。
- 同一场景的真机验证文档以 `0X-...-runtime.md` 命名，与纸面验证 `0X-...md` 配对。

## 写作规范

- 中文为主，技术术语（角色名、ZK 路径、字段名、命令）保留英文。
- 引用源码用 `path/to/file.ts:行号` 格式；引用文档用 `docs/.../X.md §N`。
- 差异表必须给出：判定（以代码为准 / 以文档为准 / 两边都对补一边）+ 修复方案（具体到改哪个文件的哪段）。
- 不引入新的代码或文档约定，只记录现状与差异。

## 不在范围内

- 自动化测试（参见 `tests/CLAUDE.md`）。
- 设计提案（参见 `docs/v0.7/prd/`、`docs/v0.7/dd/`）。
- 用户上手指南（参见根 `README.md`）。
